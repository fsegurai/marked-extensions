# Examples

Each example is complete: install, register, render.

| Example | Shows |
|---------|-------|
| [Plain JavaScript](plain-javascript.md) | All 13 extensions from the bundle and their CSS. |
| [Frameworks](frameworks.md) | React, Vue and Angular components that render 17.0.0 Markdown. |
| [Presentation](presentation.md) | A slide deck with directives, a theme and layouts. |

## Live demo

The [demo](https://fsegurai.github.io/marked-extensions) renders every extension; its playground edits Markdown live.
Run the 17.0.0 demo locally from the repository:

```bash
git clone https://github.com/fsegurai/marked-extensions.git
cd marked-extensions
bun install
bun run dev
```
