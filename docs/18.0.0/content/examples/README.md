# Examples

Each example is complete: install, render, start the browser helpers, clean up.

| Example | Shows |
|---------|-------|
| [Plain JavaScript](plain-javascript.md) | All 13 extensions from the bundle, their CSS and the browser helpers. |
| [Frameworks](frameworks.md) | React, Vue and Angular components that render Markdown and run the helpers. |
| [Editable Content](editable-content.md) | Writing kanban moves and task toggles back to the Markdown source. |
| [Presentation](presentation.md) | A slide deck with a theme, speaker view and a CSP nonce. |

## Live demo

The [demo](https://fsegurai.github.io/marked-extensions) renders every extension; its playground edits Markdown live.
Run the 18.0.0 demo locally from the repository:

```bash
git clone https://github.com/fsegurai/marked-extensions.git
cd marked-extensions
bun install
bun run start
```
