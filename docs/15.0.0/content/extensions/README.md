# Extensions

15.0.0 publishes one package, `@fsegurai/marked-extended-tables`, with the peer `marked >=13 <16`. Its default export
is the extension factory.

## Catalog

| Extension | Package (version) | Default export | Syntax summary | Browser behavior |
|-----------|-------------------|----------------|----------------|------------------|
| [Tables](tables.md) | `@fsegurai/marked-extended-tables` (15.0.0) | `markedExtendedTables` | `\|\|` colspan, `^` rowspan, multi-row headers | none |

The changelog's 15.0.0 entry also lists code preview, footnote, lists and typographic as new extensions. They are not
part of the `v15.0.0` tag; they first ship in 15.1.0.
