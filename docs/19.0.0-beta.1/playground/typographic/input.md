# Typography

"Straight quotes" become 'curly' ones, -- and --- become dashes and ... an ellipsis. 1/2 and 3/4 turn into fractions.

Code spans such as `"this"` are left alone, and so is <span class="no-smart">"this span" -- skipped by class</span>.

Shortcodes: (:alpha:) (:->:) (:check:) and (:TM^:).
