# 18.1.0

All 20 packages (18 extensions, the bundle and core) are released together as **18.1.0**, with the peer dependency
`marked ^18`.

> **⚠️ Breaking changes in a minor release.** A `^18` range picks up 18.1.0: pin `~18.0.0` to stay on 18.0 and
> follow [Migrating to 18.1](../guides/migration-18.1.md). The full list is in the
> [CHANGELOG](https://github.com/fsegurai/marked-extensions/blob/main/CHANGELOG.md).

## Highlights

- **Sanitizer-safe markup by default.** The output survives strict sanitizers such as Angular's
  `SecurityContext.HTML`: no `id`, `style`, `data-*`, `<input>`, `<button>`, `<svg>`, `<iframe>`, `<script>` or
  `<style>`. Configuration is carried by `mx-<pkg>-<key>-<value>` class tokens, and icons are CSS. `unsafeHtml: true`
  restores the 18.0 markup. See [Sanitizer-safe markup](../guides/sanitizer-safe-markup.md).
- **Explicit runtimes.** Packages no longer start interactive behavior on their own: call `attachX(root, options?)`, or
  the bundle's `attachAll(root)`, after inserting the HTML, and the returned `dispose` on teardown. Runtimes are
  scoped, idempotent and re-render safe (`attachX.refresh(root)` or `{ observe: true }`), and dispatch bubbling
  `marked-extended:<pkg>:<event>` events. See [Runtime contract](../guides/runtime-contract.md).
- **SSR-safe.** No package touches the DOM on import or when its extension is created.
- **Stable ids.** Ids are content hashes with a `-2`, `-3`… suffix for repeated blocks in one parse.

## Features

- **Runtimes**: `attachX(root, options?)` for accordion, comments, footnote, timeline, spoiler, lists, tabs, embeds,
  kanban, slide and code, with keyboard support and cancelable events where an action can be prevented
  (`tabs:before-switch`, `kanban:move`, `kanban:view`, `slide:change`, `lists:toggle`, `embeds:before-load`).
- **Bundle**: `attachAll(root, options?)` attaches every runtime and returns one `{ dispose(), refresh() }` handle; a
  failing runtime never stops the others.
- **One class convention** for every package: `mx-<pkg>`, `mx-<pkg>-<part>`, `mx-<pkg>--<modifier>`, `mx-is-<state>`,
  and custom properties `--mx-<pkg>-*` with fallbacks. Each package documents its classes and properties.
- **One extension contract**: every factory is a default and named export (`markedExtended<Name>`) returning a
  `MarkedExtension`; options types are `<Name>Options`; frozen `UPPER_SNAKE` constants (`ALERT_VARIANTS`,
  `TABS_VARIANTS`, `KANBAN_VIEWS`, `SLIDE_LAYOUTS`, `EMBED_PROVIDERS`, `LIST_TYPES`…).
- **Labels**: every user-visible string of alert, code, comments, embeds, footnote, kanban, lists, slide, spoiler,
  tabs, timeline, toc and wikilinks comes from `labels`, shallow-merged over the exported frozen `default<Name>Labels`,
  HTML-escaped and never treated as a template. `labels` also takes a function: alert, kanban, slide and comments read
  it at each parse, the other packages once at creation.
- **Themes**: `--mx-*` base design tokens (`--mx-text`, `--mx-border`, `--mx-accent`…) read by every theme stylesheet
  (accordion, alert, comments, embeds, footnote, kanban, lists, slide, spoiler, tables, tabs, timeline); defaults are
  unchanged while the tokens are unset.
- **Core slugger** (public): `slugifyHeading`, `createSlugger`, `isSafeHeadingId`, `DEFAULT_RESERVED_HEADING_IDS`.
- **Alert**: `[!TYPE]` detected while the blockquote is tokenized, so alerts work under wrapper tokens;
  `ALERT_VARIANTS`; `icon` option (`'class'` by default, sanitizer-safe; `'svg'`; `false`).
- **Code**: the fence start line is applied by `attachCode` (`--mx-code-line-offset`) and `code.css` numbers lines with
  a CSS counter; `copyText()` skips deleted lines; `prismLineHighlight` (`'set'`, `'skip'`, `'remove'`) avoids the
  clash with pages that use `data-line`.
- **Lists**: `tasksOnly: true` keeps Marked's own lists and only renders sanitizer-safe task checkboxes, with the same
  toggle event detail (`line`, `offset`, `raw`); `interactiveCheckboxes: 'attached'`, `lineOffset`; toggles keep a
  host-set `aria-label`.
- **Embeds**: privacy-first click-to-load placeholders; `attachEmbeds` builds iframe URLs only from a per-provider
  allowlist; `sandbox` extension option and `attachEmbeds(root, { sandbox })`, replacing `enableSandbox` /
  `sandboxPermissions` (which still work).
- **Footnote**: `footnoteTokenClass(id)`.
- **Typographic**: `backticks` option, `skipClasses` (for example `['katex', 'mermaid']`) and the `typographicTransform(html, options)`
  export.
- **Timeline and comments**: `locale` and `timeZone` options.
- **Accordion, comments, embeds, kanban and spoiler**: `allowedDataAttributes` runtime option.

## Fixes

- **Tables**: only `^^` merges a cell into the one above, and the marker is removed completely (before, a single `^`
  merged too and `^^` left a stray ` ^`). The documented caption syntax with one blank line now renders a `<caption>`.
- **Accordion, comments, embeds, kanban and spoiler**: custom `data-*` attributes are restored only from
  `allowedDataAttributes`; hand-written class tokens can no longer forge attributes such as `data-line`.
- **Footnote**: content is rendered with the `Marked` instance being parsed, not the global `marked`.
- **Typographic**: `breaks` applies to the instance the extension is used on, not the global `marked`; `quotes`,
  `dashes` and `ellipses` now take effect, and the output cache includes every flag.
- **Timeline**: date-only values keep their calendar date in every time zone; an event without `date` renders
  `Event N` as text instead of parsing it as a date; an event with only front matter (no body) renders its date.
- **Comments**: date-only metadata keeps its calendar date in every time zone.
- **Kanban**: cards render with the caller's `Marked` instance; priority chips no longer share the card's class token;
  drag and drop prefers the column's `data-column-id`.

## Breaking changes

Every item has a before/after entry in [Migrating to 18.1](../guides/migration-18.1.md).

- Runtime contract: interactive behavior needs `attachX(root)` or `attachAll(root)`; the default markup is
  sanitizer-safe (`unsafeHtml: true` restores the 18.0 markup).
- Removed globals, listeners and options: footnote `setupSmoothScroll` listener, timeline `init*` / `destroy*`,
  spoiler `initSpoilers` / `destroySpoilers`, tabs `window.initMarkedExtendedTabs` and `registerCallbacks`, slide
  injected script and `window.presentation`, lists `window.markedListsCallback`, kanban
  `window.updateMarkdownFromKanbanMove`; callbacks such as `onEmbedLoad`, `onCheckboxChange`, `onBeforeSwitch` and
  `onMove` are ignored with a warning.
- Runtime events are renamed `marked-extended:<pkg>:<event>` (`timeline:collapse`, `spoiler:toggle`, `kanban:move`,
  `tab-switched`, `slidechange`).
- Ids are content hashes; the tabs `persistSelection` storage key changed.
- `comments` and `embeds` narrow their `marked` peer from `>=17.0.0` to `^18`.
- Every class and custom property was renamed to the `mx-` convention, with no aliases (for example `active` →
  `mx-is-active`, `tabs-pills` → `mx-tabs--pills`, `footnote-backref` → `mx-footnote-backref`, `data-task-list` →
  `mx-lists-task-list`). Code: `LINE_CLASSES` values changed and `className` defaults to `''`. Tables: the stylesheets no
  longer style bare `table` elements.
- Tables: a single `^` no longer merges; `handleComplexSpans` and `TableCell.complexRowSpan` / `relatedCell` were
  removed; `SpanTableOptions` → `TablesOptions` (deprecated alias kept).
- Footnote: `smoothScroll` and `scrollOffset` removed from `FootnoteOptions` (pass them to `attachFootnotes`);
  footnote content no longer uses extensions registered only on the global `marked`.
- Slide: `injectScript` and `scriptNonce` removed from `SlideOptions`.
- Accordion, comments, embeds, kanban and spoiler: `data-*` front-matter values are restored only when listed in
  `allowedDataAttributes`.
- Comments: `--comment-accent` renamed `--mx-comments-accent`.
- Typographic: `breaks` is no longer global; `quotes`, `dashes` and `ellipses` follow `attribute` unless set.
- Timeline: events without `date` render `Event N` as text.
- Comments: `CommentOptions` → `CommentsOptions`; embeds: `EmbedOptions` → `EmbedsOptions` (deprecated aliases kept).
- Lists: list boundaries and looseness follow Marked: a paragraph after a blank line no longer joins the last item, a
  blank line inside an item makes the list loose (paragraphs), and a new bullet character starts a new list.
- Embeds: stricter default iframe sandbox. Generic `iframe` / `pdf` embeds get
  `allow-scripts allow-popups allow-presentation`; known third-party players keep `allow-same-origin`, never on the
  page's own origin. The `sandbox` option restores it.
- Typographic: `quotes` only affects straight quotes; backtick quotes have their own `backticks` option, so
  `quotes: false` no longer turns them off. A closing `''` becomes `”` (18.0.x rendered `’’`). The unused
  `ProcessingOptions.backticks?: number` field was removed.
- Alert: tighter spacing: `--mx-alert-padding` `0.5em 1em`, `--mx-alert-title-margin-bottom`, no outer margin on the
  body's first and last blocks.

## Not public API

`@fsegurai/marked-extended-core/internal` (fence matching, props parsing, `warnOnce`, labels and date helpers, the
`data-*` allow-list) is shared by the packages of this repository and bundled into each of them. It is not in core's
`exports` and may change in any release.

## Development

Dependencies were upgraded (marked 18.2.1, Biome 2.6.8, jsdom 31.0.1, Vite 8.3.8, portless 0.17), every package has
output and export-surface snapshot tests, and `bun run check:playground-pins` keeps every published playground on an
exact `marked` version.
