# Alerts

> [!NOTE]
> Useful information that users should know, even when skimming content.

> [!TIP] Pro tip
> A title after the marker replaces the default one.

> [!WARNING]
> Urgent info that needs immediate user attention to avoid problems.

> [!CAUTION]
> Advises about risks or negative outcomes of certain actions.

> [!RELEASE] Shipped in 18.1.0
> A custom variant registered with the `variants` option.

- Alerts are detected while the blockquote is tokenized, so they also work inside other blocks:

  > [!IMPORTANT]
  > This alert lives in a list item.
